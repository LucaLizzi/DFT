# Setup instructions
Activate the virtual environment: Run source venv/bin/activate (Linux/macOS) or venv\Scripts\activate (Windows) in your terminal.
Install requirements: Execute pip install -r requirements.txt to install all required dependencies (Python 3.13.15 is used).
Configure and run: Specify the path to your target .wav audio file inside main.py and run the program using python main.py.


# Audio Dataset Description
All three audio files were recorded using a smartphone microphone capturing an unamplified electric guitar.test1_notes: Contains individual notes A2 ($110.00\text{ Hz}$), A3 ($220.00\text{ Hz}$), D2 ($73.42\text{ Hz}$), and D3 ($146.83\text{ Hz}$).test2_notes: Contains individual notes E2 ($82.41\text{ Hz}$), D2 ($73.42\text{ Hz}$), and B3 ($246.94\text{ Hz}$).test3_notes: Contains all six open strings played individually: E2 ($82.41\text{ Hz}$), A2 ($110.00\text{ Hz}$), D3 ($146.83\text{ Hz}$), G3 ($196.00\text{ Hz}$), B3 ($246.94\text{ Hz}$), and E4 ($329.63\text{ Hz}$).
